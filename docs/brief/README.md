# Brief

The original documents a client build started from, kept exactly as supplied, for history. Nothing here is
edited after it lands — if something needs to change, change `docs/DESIGN.md` or `docs/CONTENT.md` instead
and log why in `docs/MEMORY.md`.

- `design-system.md` — the studio's design system document
- `content.md` — the content team's page copy, metadata and content structure document

Empty in the base theme. A client build adds these two files here at the start of the project.
